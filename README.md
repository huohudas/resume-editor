# ✨ 简历经历修改器 (Resume Editor)

基于 **DeepSeek-V3** 驱动的智能简历优化工具。专为产品经理及互联网从业者设计，致力于将平淡的项目描述转化为具有竞争力的专业经历。

### 🌟 核心亮点
- **深度 JD 匹配**：AI 会深度分析目标岗位描述（JD），确保生成的经历与招聘需求高度契合。
- **黄金字数法则**：输出严格遵循 **45-48 字** 长度限制，完美适配简历单行排版，治愈强迫症。
- **四字精准概括**：自动为每段经历生成 **“四字小标题”**（如：**[架构迭代]**），让面试官一眼抓取核心能力。
- **思考过程可见**：开启“思考开关”即可观察 AI 如何拆解 JD 并进行逻辑优化的全过程。

### 📝 优化示例 (Before & After)

**原始输入 (Input):**
> “负责公司后台系统的开发，主要是改改 Bug 和增加一些新功能，提升了用户的使用效率。”

**优化后输出 (Output):**

* **[架构重构]** 主导后台系统架构重构，通过模块化解耦提升扩展性，降低系统维护成本约 30%。
* **[性能优化]** 深度优化数据库查询逻辑，引入 Redis 缓存机制，使核心接口响应速度提升 50%。
* **[质量保障]** 建立自动化测试体系，覆盖核心业务场景，成功将线上故障率降低至 0.1% 以下。
* **[效能提升]** 针对用户高频操作路径进行功能迭代，通过数据埋点分析，提升用户操作效率 40%。

> **注**：每条经历均包含精准的四字概括，且字数严格控制在 45-48 字之间（含标点）。

### 🛠️ 快速开始
所有操作均在**主页面**一站式完成，无需跳转：

1.  **输入目标岗位**：填写你想应聘的职位名称（如：产品经理）。
2.  **填写真实经历**：将你的原始项目经历粘贴到输入框中。
3.  **粘贴 JD (可选)**：为了效果更精准，建议粘贴目标岗位的 JD 描述。
4.  **一键修改**：点击按钮，AI 即刻生成结构化的简历描述。
